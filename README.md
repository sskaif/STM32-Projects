🚀 STM32 Projects Repository

Welcome to my STM32 Projects repository! 🎉
This repository contains hands-on projects with STM32 microcontrollers, ranging from beginner to advanced level. It’s designed for learning, experimentation, and showcasing skills in embedded systems.

🌟 Repository Contents

This repository includes projects such as:

🔹 Beginner Level

LED Blink 💡 – Learn the basics of GPIO by blinking an LED.

Button Controlled LED 🔘 – Control LEDs with push buttons.

🔹 Intermediate Level

Ultrasonic Smart Dustbin 🗑️ – Automatically opens the lid using an ultrasonic sensor and a servo motor.

Traffic Light Controller 🚦 – Simulate traffic lights using timers and LEDs.

Temperature & Humidity Monitor 🌡️ – Read sensor data and display it via UART or LCD.

🔹 Advanced Level

Home Automation System 🏠 – Control appliances with sensors and Bluetooth modules.

Motor Speed Control ⚙️ – PWM-based motor control using STM32 timers.

IoT Sensor Node 🌐 – Send sensor data to a cloud platform using ESP8266/ESP32 with STM32.

(More projects will be added regularly!)

🔧 Features

Hands-on STM32 development with HAL & Low-Level drivers

GPIO, Timers, ADC, UART, PWM implementations

Interfacing with sensors and actuators

Step-by-step project explanations included

Suitable for beginners to intermediate learners
